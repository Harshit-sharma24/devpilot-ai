# 🚀 DevPilot AI

AI-powered developer toolkit for Visual Studio Code.

DevPilot AI helps developers generate project files, analyze codebases, fix missing project essentials, and bootstrap new projects—all directly inside VS Code.

---

# ✨ Features

## 📄 Create README
Generate a professional README.md for your project.

## 📦 Create package.json
Generate a ready-to-use package.json file.

## 📃 Create LICENSE
Generate an MIT LICENSE instantly.

## 🚫 Create .gitignore
Create a clean .gitignore for your project.

## 🏗 Project Setup
Generate the basic folder structure for new projects.

## 🔍 Analyze Project
Analyze your project and display:

- Project Health Score
- Framework Detection
- Language Detection
- Dependencies
- Dev Dependencies
- Missing Files
- Improvement Suggestions

## 🤖 Smart README
Automatically generate or update README.md based on your existing project.

## ⚡ Generate Boilerplate
Create boilerplate templates for common project types.

## 🛠 Fix Project
Automatically detect and fix missing project essentials.

---

# 📋 Commands

Open the Command Palette (`Ctrl + Shift + P`) and run:

- DevPilot AI: Create README
- DevPilot AI: Create package.json
- DevPilot AI: Create LICENSE
- DevPilot AI: Create .gitignore
- DevPilot AI: Project Setup
- DevPilot AI: Analyze Project
- DevPilot AI: Smart README
- DevPilot AI: Generate Boilerplate
- DevPilot AI: Fix Project
